# Welcome to Physical AI Textbook

Learn **Physical AI, Robotics, and ROS 2** from scratch.

## What is Physical AI?

Physical AI combines artificial intelligence with robotics and physical systems. This textbook will guide you through:

- 🤖 **ROS 2** - Robot Operating System fundamentals
- 🔧 **Sensors & Actuators** - Hardware interfacing
- 🧠 **Computer Vision** - Perception for robots
- 🎯 **Motion Planning** - Navigation and control
- 🚀 **Real-world Projects** - Hands-on implementations

## Course Structure

This textbook is organized into progressive modules:

### Module 1: Introduction to Physical AI
Get started with ROS 2, nodes, topics, and basic robotics concepts.

### Module 2: Perception Systems (Coming Soon)
Learn computer vision, sensor fusion, and environment mapping.

### Module 3: Motion & Control (Coming Soon)
Master navigation, path planning, and robot control algorithms.

## Prerequisites

- Basic Python programming knowledge
- Familiarity with command line/terminal
- Ubuntu 22.04 or Docker environment

## Getting Started

Ready to begin? Start with **[Module 1: Introduction](/docs/module-1/intro)** to learn ROS 2 fundamentals.
